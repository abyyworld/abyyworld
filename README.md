### 🔬 Research

**DreamCodeVR: Error Feedback in Immersive Voice Programming**
Wizard-of-Oz user study on how people understand, attribute, and recover from AI-generated code errors in VR. Extends a live voice-to-code system (speech to LLM to Unity C#, compiled in-scene) with three controlled feedback conditions: none, explanatory text panel, and embodied conversational agent. Built the full experimental infrastructure: scripted error injection, condition management, a hidden researcher control interface, and per-participant logging. Manuscript in preparation.
[Repository](https://github.com/abyyworld/Real-Time-Immersive-Speech-Programming)

**Omni-Connect / DeviceSphere: Cross-Device Interaction**
A laptop, phone, and tablet operating as one connected workspace: native Unity coordination server plus zero-install WebGL clients over the local network. Features a novel gesture-driven copy-paste interaction captured with Meta Project Aria glasses, and a real-time WebSocket-to-UDP bridge. Full infrastructure for two controlled user studies.

**LLM Bias Mini-Evaluation**
Reproducible evaluation of directional gender bias across BERT, RoBERTa, and GPT-2 using masked-language-modeling and open-generation prompts.
